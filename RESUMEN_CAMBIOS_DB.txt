📋 CAMBIOS NECESARIOS:
--------------------------------------------------------------------------------

1. CREAR PÁGINA "NOTICIAS"
   - Tabla: wp_posts
   - Acción: INSERT nueva página
   - Campos:
     * post_title = 'Noticias'
     * post_name = 'noticias'
     * post_type = 'page'
     * post_status = 'publish'

2. ASIGNAR TEMPLATE A PÁGINA NOTICIAS
   - Tabla: wp_postmeta
   - Acción: INSERT/UPDATE
   - Campos:
     * meta_key = '_wp_page_template'
     * meta_value = 'page-noticias.php'

3. CREAR PÁGINA "INICIO"
   - Tabla: wp_posts
   - Acción: INSERT nueva página
   - Campos:
     * post_title = 'Inicio'
     * post_name = 'inicio'
     * post_type = 'page'
     * post_status = 'publish'

4. CONFIGURAR WORDPRESS
   - Tabla: wp_options
   - Acción: UPDATE 3 opciones
   
   a) page_on_front
      * Antes: 0
      * Después: [ID de página "Inicio"]
   
   b) page_for_posts
      * Antes: [ID de página "Noticias"]
      * Después: 0
   
   c) show_on_front
      * Antes: puede variar
      * Después: 'page'

🔧 COMANDO SQL RÁPIDO (si prefieres manual):
================================================================================

-- Verificar IDs actuales
SELECT ID, post_title, post_name FROM wp_posts 
WHERE post_type = 'page' AND post_name IN ('inicio', 'noticias');

-- Si las páginas NO existen, ejecuta el script completo:
-- update-noticias-produccion.sql

-- Si las páginas YA existen, solo actualiza la configuración:
UPDATE wp_options SET option_value = 'page' WHERE option_name = 'show_on_front';
UPDATE wp_options SET option_value = '0' WHERE option_name = 'page_for_posts';
UPDATE wp_options SET option_value = '[ID_PAGINA_INICIO]' WHERE option_name = 'page_on_front';
